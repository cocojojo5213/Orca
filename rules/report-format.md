# SRC 漏洞报告格式（正式报告唯一版式）

本文件是原 `~/.grok/rules/vuln-report-format.md` 的自包含本地版。
中危及以上确认后立刻按此落 `报告/`，文件名 `报告/<漏洞名>-<YYYYMMDD>.md`。
定级只认本文件，知识库不定级。

## 版式

```
# <漏洞标题>（<漏洞类型> · <等级>）

- 目标：URL / 资产 / 归属业务
- 漏洞类型：OWASP 类目
- 危害等级：严重 / 高危 / 中危 / 低危 + 一句话理由
- 接口：method + 完整 URL + 关键参数
- 权限要求：未登录 / 低权账号 / 任意会话

## 复现步骤
1. 前置条件
2. 请求（关键头/体；敏感凭证打码）
3. 预期 vs 实际回包（差分对照，证明不是公开数据）

## 影响
- 谁受影响、数据/能力损失范围
- 不夸大：不把「能读公开稿」写成「接管」

## 修复建议
- 最小修复：鉴权 / 校验 / 边界收紧的具体位置

## 附（测试自证）
- 仅用读/差分/可回退写入；未触碰他人存量数据；会话全程未登出
```

## 规则

- 中危升链/换站认 `rules/engagement-guide.md` §4.3。
- 每条报告必须带复现差分证据；无证据不落盘，落盘即认定级成立。
- 报告正文中文；接口/回包原文保留。
