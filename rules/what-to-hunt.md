# 挖什么（交什么 / 不交什么 / 力气先砸哪）

本文件是原 `~/.grok/rules/src-value-hunting.md` 的自包含本地版。

## §1.1 力气先砸哪（有差分面才真打）

按序投入，前面的优先：

1. **认证/会话**：任意登录、账号接管、未登录改密/改绑/换票、票里带他人身份
2. **越权（读优先）**：跨用户/跨租户敏感读（他人手机/证件/账单/正文）
3. **未授权敏感读**：不登录直出他人/内部数据
4. **逻辑写**：支付/券/积分/状态变更（能证明真变、能改回）
5. **注入类四件套**：注入/SSRF/XSS/RCE —— 有差分面必须真打、不得连日空窗；
   不是只测这四类，也不是每个 path 喷 `'`
6. **信息泄露**：完整账密/云密钥/证件样例/私钥（有实值才算）

## 不交

- CORS 一律不挖不写（勿开 `knowledge-base/cors-test.md`）
- 点击劫持缺头不写；CRLF/DNS 重绑定/CSV 公式/HPP/HTTP2 变体 几乎不交
- LLM 越狱教材不挖（`knowledge-base/llm-security-test.md` 禁开）；登录页 HTML 不磨
- 假点：必须对照「不带这条件应失败」。只出自己的数据、只出公开运营稿、token 过期、
  占位符密钥、演示空号 —— 全部不算

## 定级锚点（定级只认 `rules/report-format.md`）

- 严重：RCE / 全站接管 / 核心库数据
- 高危：大范围越权 / 任意用户敏感数据 / 完整云钥
- 中危：单点敏感泄露 / 逻辑写
- 低危：低敏感信息泄露 / 无害误配
