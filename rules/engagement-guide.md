# 进站打法（黑盒 SRC 流程权威）

本文件是原 `~/.grok/rules/dig-scope-workflow.md` 的自包含本地版。
knowledge-base/短表引用的 §1.0.1、§1.6、§2.1.4、§4、§4.1.1、§4.2.2、§4.2.3、§4.3 均指本文件对应小节。
冲突时以本文件 + `rules/what-to-hunt.md` + `rules/report-format.md` 为准。

## §1 种子闭环（自由跳节奏）

### §1.0.1 一种子闭环
- 搜一个种子 → 去重去废去非存活 → 剩余活面全部挖完 → 标 done → **立刻**搜下一条 pending。
- 禁止多种子一次搜完再挖；禁止「一轮搜完」当收工；「资产条数到手」不是换种理由。
- 优质根域只回灌（记进 `种子队列.md` 回灌栏），本种子挖完才搜新种。

### §1.6 回合结束
- 收工 = 本种子剩余活面已挖完，然后换种子继续，不是整场停。
- 回合结束前必读 `种子队列.md`；有 pending 禁止以问句收尾停住。
- 禁止停工问：「要不要继续」「其它品牌要不要也挖」「下一步您看」。

## §2 资产测绘

### §2.1 一个种子只搜当前资产
- 认到短表形态只打当前站，禁止拿形态去全网回扫。
- 本机无 FOFA MCP，资产来源按序：
  1. `websearch` 工具按品牌/集团名搜资产线索（官网、子域、备案、开源仓库、新闻稿里的域名）
  2. `curl "https://crt.sh/?q=%.<根域>&output=json"` 被动子域枚举
  3. 目标自身 JS / 接口 / 登录页 / 移动端包里的 host
  4. 股权线索：全资子公司域并入种子队列（禁止队列只有原词一条）
- 去重去废去非存活：只留活面。

### §2.1.4 限流闸
- 本机没有 FOFA 三账号自动切换。搜索走 `websearch`，一个查询只服务当前种子；
  被限流/无结果时换查询词，不换种子。

## §4 进站打法

进站先短表（`knowledge-base/quick-hits.md`），对得上就开模块；然后立刻按本节推进：
先说清这摊、JS 抽钥匙、回包进清单。

### §4.1 登录页/壳处理

### §4.1.1 打开是登录页
- 先找业务面：本 host 网关或跳转后的 host；没会话时主业挖未登录。
- 登录表单看得见的打通或证伪就停；繁琐验证 / 别人的身份页 / 同皮壳不耗。
- 清单里有 发会话 / 重置 / 改绑 / 换票 → §4.2.2（有入口勾，无入口 N/A）。
- 看见登录页不是换资产。不是登录相关一律不管。

### §4.2 认证与对象

### §4.2.1 进站勾完标准（差分勾法）
- 能看出条数/内容变化的口，每个过滤参都测；只回「请登录」整段 N/A。
- 按栈选探针：JSON/Mongo 操作符、搜索框 ES、Java HQL/SpEL、有模板 SSTI；SQL 面仍走引号/布尔/延时。405 后换位置不只有换编码。

### §4.2.2 认证口
- 发会话 / 重置 / 改绑 / 换票 相关入口按 `knowledge-base/authbypass-test.md` 打。
- 禁止登出/注销/吊销令牌；改绑/改密过了立刻改回，不要把用户号改死。

### §4.2.3 对象图 / 换 id / 哨兵值（有会话时的最低探针）
- 从列表/回包里抄**他人**对象 id、租户号、哨兵值（0/-1/空），换进详情/写口。
- 单号难注册第二号时：用列表/回包里的他人 id，不为第二号磨注册。
- 写越权顺序：**先添加**（看能不能挂到别人名下）→ **再删自己刚加的那条**。
  不要改/删别人已存在的订单、地址、密码、角色。
- 没有创建口、只能动现成对象：只改能改回去的测试字段，打一次；
  改密/改角色/改绑按 §4.2.2 可探（拿掉旧验看是否过），过了立刻改回；改不回停在回包。
- 禁止批量、禁止真资损、禁止把用户号改死。

### §4.3 中危升链 / 换站
- 中危及以上确认后：立刻按 `rules/report-format.md` 落 `报告/`。
- 中危升链：同一站内顺着数据/权限链往高打（信息泄露 → 越权 → 接管），不换站。
- 换站：本种子剩余活面挖完才换，不是出一条中危就换。
